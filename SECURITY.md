# Security and data-handling policy

## Synthetic data only

LeakLab is a development and education project. It must only process records generated by its own synthetic-data generator or other clearly fictional fixtures.

Do not add functionality to:
- ingest or search real breach dumps or stolen datasets;
- collect, test, validate, or expose passwords, authentication tokens, session cookies, or API keys;
- identify real people from exposed data;
- scrape services or bypass access controls.

The generator uses reserved `.invalid` email domains and fabricated identifiers. It must not derive records from real individuals.

## Reporting

Please do not submit real personal information, credentials, or breach samples in issues or pull requests. Describe problems using synthetic examples only.
