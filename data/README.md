# Generated datasets

Daily datasets are generated by the **Daily Synthetic Dataset** GitHub Actions workflow.

The workflow creates fictional profile records and fictional password samples in JSONL and CSV formats, plus an aggregate-only manifest. It uploads the bundle as a GitHub Actions artifact for 14 days rather than committing generated data to the repository.

No breach corpus, RockYou records, real passwords, or real account credentials are used. The daily seed is derived from the UTC date, so a rerun on the same date reproduces the same sample values.

To generate a bundle locally:

```powershell
python -m pip install .
python -c "from datetime import date; from pathlib import Path; from leaklab.daily import build_daily_bundle; build_daily_bundle(date.today(), Path('build/daily-dataset'))"
```
